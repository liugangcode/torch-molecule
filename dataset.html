Datasets¶

Model inputs are lists of SMILES strings. For supervised prediction, add a numerical target array with shape (n_molecules, n_tasks). Dataset loaders return a SMILESDataset with data and target attributes; unlabeled datasets have target=None.

Collection statistics¶

Explore small-molecule and polymer datasets in the molecular dataset hub, including their original sources, licenses, quality tags, and available data.

Read the hub’s current counts or select the figure to explore its interactive map. Hugging Face entries include public and gated datasets, and some provide files instead of SMILES tables. Source rows can repeat structures and are not a count of unique molecules. Each dataset retains its own license.

Load a dataset¶

load_dataset loads any dataset of the molecular dataset hub by name, the way scikit-learn’s loaders do:

from torch_molecule.datasets import load_dataset

X, y = load_dataset("qm9", targets=["gap"], return_X_y=True)

Without return_X_y you get a SMILESDataset that also says what the numbers are:

data = load_dataset("qm9", targets=["homo", "lumo", "gap"])
data.data[:2], data.target.shape     # SMILES, (133885, 3)
data.info["targets"]["gap"]["units"] # 'Hartree'

Some datasets hold several tables, one per target, assay, or property; name one as the second argument. MoleculeACE has one per protein target:

data = load_dataset("moleculeace", "chembl204_ki")
data.info["title"]                                  # 'Prothrombin (CHEMBL204) · Ki'
data.info["targets"]["y [pEC50/pKi]"]["about"]      # ChEMBL target, organism, UniProt

list_datasets() lists the hub, optionally by text, category, or quality grade; dataset_info(name) describes one dataset and its configs:

from torch_molecule.datasets import dataset_info, list_datasets

list_datasets("thrombin")                    # finds moleculeace by a config title
list_datasets(category="adme", grade="ready")
[t["config"] for t in dataset_info("moleculeace")["tables"]]

Labels stay as the source reported them: missing labels are NaN (never 0), and censored values such as <10 are NaN unless include_censored=True. Datasets that cannot be redistributed are listed too; loading one raises an error that names the original source. Gated datasets need huggingface-cli login and an accepted access request on the dataset page. Files download on first use to ~/torchmol_data (set TORCHMOL_DATA or local_dir= to change it); release="v2026.10.31.3" pins a hub release. Names from earlier releases, such as moleculeace_chembl204_ki, still load.

Note

This interface is newer than the 0.2.0 release on PyPI. Until the next release, install from GitHub: pip install git+https://github.com/liugangcode/torch-molecule.

Bring your own data¶

Pass SMILES directly to a model, or wrap them in SMILESDataset to use the built-in splitting tools. For an unlabeled CSV with a smiles column:

import csv
from torch_molecule.datasets import SMILESDataset

with open("data/molecule100.csv", newline="") as handle:
    smiles = [row["smiles"] for row in csv.DictReader(handle)]

data = SMILESDataset(data=smiles, target=None)

The source checkout includes data/molecule100.csv and data/polymer100.csv for small local examples. Both contain SMILES; the polymer dataset uses * attachment atoms. Check the selected model’s support for polymer inputs and attachment atoms before using it for polymer generation.

Choose a split¶

When the source defines a split, load it by name, so results compare with published ones. A test split drops molecules that also appear in training:

train = load_dataset("moleculeace", "chembl204_ki", split="train")
test = load_dataset("moleculeace", "chembl204_ki", split="test")

Some benchmarks provide several splits, for example five scaffold and five random splits in WelQrate. scheme picks one; the default is the first:

for scheme in ["scaffold_1", "scaffold_2", "scaffold_3"]:
    train = load_dataset("welqrate", "aid1798", split="train", scheme=scheme)
    test = load_dataset("welqrate", "aid1798", split="test", scheme=scheme)

Otherwise split the dataset yourself:

data = load_dataset("polymer_gas_permeability", targets=["CO2"])
train, validation = data.train_test_split(
    test_size=0.2,
    method="random",
    seed=42,
)

Pass train.data and train.target to fit; supply the validation data through X_val and y_val when the model supports them. Keep a separate test set for a final performance estimate. data.groups holds a structure key per row, but the splitters preserve this metadata without using it to assign rows. Random splitting assigns individual rows, so repeated structures can occur in both splits. Use scaffold or butina, or split by group yourself, when repeated measurements must stay together.

More than SMILES and numbers¶

columns returns other source columns next to the labels, row for row, in data.extra; they follow the rows through train_test_split:

data = load_dataset("welqrate", "aid1798", columns=["CID"])
data.extra["CID"][:3]           # PubChem compound IDs

Some tables hold one row per measurement, with a task column such as an assay ID. task_values lists the tasks, most-measured first; each one you pass becomes a target column:

from torch_molecule.datasets import task_values

assays = task_values("cara", "lo_all")
data = load_dataset("cara", "lo_all", task_values=assays[:10])

For tables that are not SMILES and numbers (question and answer text, reactions, mixtures), load_table returns every column as a pyarrow.Table; download_files fetches native files such as 3D structures, spectra and images:

from torch_molecule.datasets import download_files, load_table

questions = load_table("fgbench", split="test").to_pandas()
paths = download_files("qm9", patterns=["structures/*"])

Loader reference¶

load_dataset(name, config=None, *, split=None, targets=None, return_X_y=False, scheme=None, task_values=None, columns=None, include_censored=False, drop_leaked=True, local_dir=None, release=None)[source]¶

Load a hub dataset: SMILES and their labels.

Parameters:

  • name (str) – Dataset name from list_datasets(), for example "qm9" or "moleculeace".

  • config (str, optional) – Which table, for datasets with several (one per target, assay, or property); dataset_info(name)["tables"] lists them. Datasets with one table need none.

  • split (str, optional) – A source split such as "train" or "test"; default all rows.

  • targets (list of str, optional) – Label columns to load; default all of the table’s.

  • return_X_y (bool, default=False) – Return (smiles, target) instead of a SMILESDataset.

  • scheme (str, optional) – For sources with several splits ("scaffold_3", "random_1" in WelQrate), which one split refers to; default the first. Rows it leaves out are not loaded.

  • task_values (list of str, optional) – For tables with one row per measurement and a task column (an assay or target ID): the tasks to load, each as one target column. task_values() lists them.

  • columns (list of str, optional) – Other source columns to return in dataset.extra (identifiers, conditions, dates).

  • include_censored (bool, default=False) – Censored labels such as <10 load as NaN, or as their bound (10) when True.

  • drop_leaked (bool, default=True) – A non-train split leaves out molecules that are also in the train split.

  • local_dir (str, optional) – Download cache; default $TORCHMOL_DATA or ~/torchmol_data.

  • release (str, optional) – Hub release tag (e.g. "v2026.10.31.3") for reproducible results; default the latest.

Returns:

data holds canonical SMILES (mixture components joined with .), target an (n_molecules, n_targets) array with NaN for missing labels, groups the structure key of each row, extra the requested columns, and info the description, units, readable label names, splits, license, sources, and quality. With return_X_y=True, (data, target).

Return type:

SMILESDataset or tuple

subsample(n, seed=0)[source]¶

Draw a random subset without replacement.

Intended for local debugging and CI, not as a way to make structure- aware splits cheaper. Do not subsample a benchmark (for example QM9) because Butina is slow or memory-heavy; that changes what the split measures.

Parameters:

  • n (int) – Number of molecules to keep.

  • seed (int, default=0) – Random seed.

Return type:

SMILESDataset

train_test_split(test_size=0.2, method='random', seed=42, **kwargs)[source]¶

Split into train and holdout SMILESDataset objects.

Parameters:

  • test_size (float, default=0.2) – Requested holdout fraction.

  • method ({"random", "scaffold", "butina", "size"}, default="random") – random assigns individual rows, so duplicate structures can appear in both splits. groups metadata is not used to assign rows. scaffold holds out unseen Bemis-Murcko scaffolds; butina holds out unseen Taylor-Butina clusters; size splits by heavy-atom count.

  • seed (int, default=42) – Random seed (used by random).

  • **kwargs – Extra options forwarded to the splitter (use_csk for scaffold, similarity_cutoff for butina, direction / mode for size).

Returns:

train, holdout – The second dataset is intended as validation data for fit.

Return type:

SMILESDataset
