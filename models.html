Model collection¶

Choose from 31 model classes for property prediction, molecular representations, and generation. Models accept SMILES strings and handle their own graph or sequence representations. Select a model below to see its parameters and method signatures. Example links open the code directly in each model’s reference page.

Predict properties¶

Fit on molecules and labels, then predict regression or classification targets. Start with GNN for a graph baseline or a SMILES model for a sequence baseline.

Train a generator on molecules or load a pretrained model. Conditioning varies by method: property labels, molecular scaffolds, and scored demonstrations serve different purposes and have different input formats.
